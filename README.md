# 課表行事曆

一個純前端、不需要後端的個人行事曆網站。沒有通知、沒有提醒，只負責把課表訊息轉成日期建檔。

## 放上 GitHub Pages（步驟）

1. 到 https://github.com 新增一個 repository，例如叫 `my-schedule`（Public 或 Private 都可以，Private 也能開 Pages）。
2. 把這個資料夾裡的 `index.html`、`manifest.json` 兩個檔案上傳到該 repository 的根目錄（GitHub 網頁右上角「Add file → Upload files」拖進去即可，不需要用指令）。
3. 進 repository 的 **Settings → Pages**。
4. 「Source」選 `Deploy from a branch`，Branch 選 `main`，資料夾選 `/ (root)`，按 Save。
5. 等 1～2 分鐘，頁面上會出現一個網址，格式類似：
   `https://你的帳號.github.io/my-schedule/`
6. 打開這個網址就是你的行事曆。把它加到手機主畫面（Safari／Chrome 的「加入主畫面」）或存成瀏覽器書籤，之後直接點就能用。

## 使用方式

- **貼上訊息自動解析**：把類似「週三 14:30-15:30、16:30-18:00 ... 以上時段可以在翠屏校觀課BUZZ」的文字貼進「貼上訊息，自動解析建檔」的欄位，按「解析文字」。
  - 只寫「週三」「週五」這種星期幾 → 自動抓**最近（含本週）**的日期。
  - 文字裡如果出現「下週／下周」或明確日期（如 `8/17`、`115/08/17`）→ 改成從下週起算，或直接採用該日期。
  - 解析完會先出現一個可編輯的表格，日期／時間／標題都能手動修改或刪除某一列，確認沒問題再按「加入行事曆」。
- **手動新增單筆**：下方也有一個簡單表單，可以直接輸入日期、時間、標題新增一筆。
- 日曆上點任何一天，會跳出當天的清單，可以在裡面刪除單筆行程。
- 日期在畫面上都會用民國年格式顯示（例如 `115/08/19`）。

## 資料存在哪裡

所有行程資料只存在瀏覽器的 `localStorage`，沒有任何伺服器或帳號系統：

- 優點：完全免費、沒有隱私外洩疑慮、部署完全靜態。
- 限制：資料綁在「這台裝置的這個瀏覽器」。如果你在手機 Safari 建的資料，不會自動出現在電腦 Chrome 上；清瀏覽器資料／換手機也會遺失。
- 如果之後需要跨裝置同步，可以再加一個簡單的雲端儲存（例如串接一個免費的 Google Sheet 或小型資料庫），但那會需要多一層設定，目前先用最簡單、最穩定的本機儲存版本。
